Historical upstream checks remain dated 2026-09-20. See [current research](current-source-check.md) for this edition’s actual verification. Community model labels are creator claims. Editorial adaptations are not the original render prompts and have not been generation-tested here.

FLAQ API billing and affiliate promotions were removed because they are not evidence of SeaImagine’s product terms. No API schema, no-subscription offer or guaranteed uptime is inferred from the source repository.
